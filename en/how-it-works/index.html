A short, complete path

Move through Level 0 at your pace and finish with something verifiable.

Consuming resources in order does not ensure learning unless you pause to practise and review.

The journey connects preparation, practice and transfer in a sequence you can resume.

Set aside 90 to 120 minutes, work on a real case and use resources as questions arise.

Close with a short explanation, one reviewed source and a defined next repetition.

01

Choose something real

Start with a concrete question, task or decision. Gather a few sources, but make sure you can open and inspect them.

  • A clear question
  • Available sources
  • A useful outcome
02

Read and practise

Use the masterclass to get oriented and the workbook to do the work. Pause when a claim lacks support or something is unclear.

  • Move in blocks
  • Keep citations
  • Record decisions
03

Do it again

Use the playbook and prompt library to repeat the method with another situation, not to repeat an answer.

  • Change the case
  • Check again
  • Adjust the process
04

The test is whether you can explain it

The path works if you can show which sources you used, what you decided and how you would produce another reviewable result.
