Todo lo necesario para empezar

Elige el recurso que responde a tu siguiente duda.

Abrir todo a la vez añade fricción y oculta qué necesitas aprender primero.

Cuatro recursos cumplen funciones distintas: comprender, practicar, repetir el método y formular instrucciones.

Usa la masterclass para contexto, el workbook para practicar, el playbook para sostener y los prompts para dirigir.

Sabrás que elegiste bien si el recurso produce una decisión o resultado observable.

01

Masterclass

Una presentación oficial de 18 páginas, con guía accesible, para entender el punto de partida y el hilo del recorrido.

Abrir masterclass
02

Cuaderno de práctica

El workbook reúne hojas para convertir una pregunta en práctica: buscar fuentes, guardar citas y documentar decisiones.

Abrir workbook
03

Guía para repetir

El playbook explica el método para aprender con fuentes, reconocer el espejismo de fluidez y repetir con criterio.

Abrir playbook
04

Instrucciones adaptables

La biblioteca reúne prompts listos para adaptar. Son puntos de partida para pensar mejor, no respuestas para aceptar sin revisar.

Abrir biblioteca
