# Prompt levels — adversarial UI critique

## Verdict before remediation

The prompt library preserved MetodologIA branding and responsive reflow, but exposed implementation formats as if they were user choices. Thirteen repeated libraries produced 52 keyboard stops, mixed-language labels, undersized text and an unusable no-JavaScript wall of prompts.

## Independent assessments

### Assessment A — Design director

- Replace technical format names with one pedagogical Level 1–4 convention.
- Explain that levels represent structure, not quality or difficulty.
- Replace three compressed prompt columns with a full-width progressive flow.
- Remove nested scrolling and strengthen type hierarchy.
- Make copying contextual to the selected level.

### Assessment B — Detector/browser

- Implement roving tab focus plus Arrow, Home and End navigation.
- Localize visible and accessible labels in ES, EN and PT.
- Announce copy success through a localized live region.
- Hide inert tab/copy controls without JavaScript and use native disclosure.
- Preserve 44 px targets, contrast and zero horizontal overflow.

## Implemented direction

The internal deterministic formats remain `natural`, `parameters`, `spec` and `pair`. Their public convention is now:

1. Direct — clear conversational instruction.
2. Structured — explicit inputs, flow and output.
3. Specified — contract, boundaries and verification.
4. Orchestrated — reusable system/user separation.

The interface applies the convention consistently to all 13 prompt libraries through four inline numeric controls. Full level names remain only as accessible names. JavaScript enhances native disclosures into the compact selector; without JavaScript, Level 1 opens by default and the remaining levels stay available as honest numeric disclosures.

## Acceptance

- Exactly four localized levels per prompt.
- One tab stop per level group; Arrow/Home/End navigation.
- Localized level description and contextual copy status.
- No nested prompt scrolling.
- No inert prompt controls without JavaScript.
- ES/EN/PT structural parity, 320 px reflow and WCAG 2.2 AA.
